## Порядок работы с документами

Источником истины является Markdown. PDF генерируются из него командой `make docs`
и коммитятся, поскольку формат сдачи проектной работы требует Markdown или PDF.
Править PDF вручную не следует - изменения будут потеряны при пересборке.

Диаграммы размещаются в [`diagrams/`](diagrams/) в формате Mermaid, чтобы они
версионировались как текст и были видны в diff. Схемы C4, развёртывания,
последовательности и модели данных появятся здесь на этапе HLD.
