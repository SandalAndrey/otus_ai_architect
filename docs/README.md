## Порядок работы с документами

Документы ведутся и хранятся в Markdown. Формат сдачи проектной работы допускает
Markdown или PDF, поэтому промежуточные PDF в репозитории не хранятся: они дают
шум в diff и расходятся с исходником. При необходимости PDF собирается локально
из Markdown и в репозиторий не коммитится.

Диаграммы размещаются в [`diagrams/`](diagrams/) в формате Mermaid, чтобы они
версионировались как текст и были видны в diff. Схемы C4, развёртывания,
последовательности и модели данных появятся здесь на этапе HLD.
