# Шаблон запроса на изменение (Change Request)

Инструмент к условию C-03 договора: потолок действует при неизменном объёме,
любое изменение оформляется этим документом с оценкой влияния на потолок.

Запрос заполняется до начала работ по изменению. Устная договорённость
изменением объёма не считается и потолок не сдвигает.

---

## CR-NNN. Название изменения

- **Дата:**
- **Инициатор:**
- **Статус:** Предложено / Утверждено / Отклонено / Отложено

### 1. Суть изменения

**Как сейчас:**

**Как должно стать:**

**Зачем:** какую задачу Заказчика это решает. Формулировка "так удобнее"
недостаточна для оценки: без понимания задачи невозможно предложить более
дешёвую альтернативу.

### 2. Влияние на архитектуру

| Компонент | Что меняется |
| --------- | ------------ |

Отдельно указать: появляются ли новые внешние зависимости, меняется ли модель
данных, затрагивается ли контур разграничения доступа. Изменения в последнем
требуют отдельного ADR и повторной проверки блокирующего критерия приёмки.

### 3. Влияние на проект

| Параметр                                 | Оценка |
| ---------------------------------------- | ------ |
| Трудоёмкость, ч (опт. / ожид. / пессим.) |        |
| Влияние на потолок этапа                 |        |
| Влияние на срок                          |        |
| Новые риски                              |        |
| Влияние на стоимость владения            |        |

Если изменение вытесняет ранее согласованные работы, указать какие именно.
Требования уровня Must вытеснению не подлежат.

## Пример заполнения

**CR-001. Генерация подборки товаров в PDF по итогам диалога**

*Суть.* Сейчас ассистент отвечает текстом со ссылками на артикулы. Требуется
отдавать покупателю оформленную подборку в PDF для отправки в мессенджер.

*Влияние на архитектуру.* Добавляется сервис генерации документов; требуется
временное хранилище файлов и политика их удаления; ссылки на файлы становятся
новой поверхностью атаки - файл не должен быть доступен по перебору
идентификатора. Контур разграничения доступа затрагивается: в подборку не
должны попадать позиции вне грифа пользователя, то есть проверка прав нужна и
на этапе генерации файла.

*Влияние на проект.* Трудоёмкость 40 / 70 / 130 ч. Потолок этапа 1
увеличивается на 70 ч. Новый риск: рост стоимости хранения при большом числе
подборок.

*Альтернативы.* Ссылка на страницу подборки на сайте вместо файла - 16 ч, не
требует хранилища и снимает риск утечки по ссылке. Отклонена Заказчиком:
покупателю нужен файл для пересылки.

*Решение.* Отложено в этап 2: изменение не относится к требованиям уровня Must
и вытесняет работы по интеграции с учётной системой.
