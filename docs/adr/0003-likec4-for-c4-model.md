# 0003. Вести модель C4 в LikeC4

- **Статус:** Принято
- **Дата:** 2026-08-18
- **Связанные требования:** пакет архитектурной документации, раздел 7.1 БФТ

## Контекст

Требуется представить контекст, контейнеры, компоненты, развёртывание,
последовательность и модель данных. Шесть диаграмм, описывающих одну систему.

Ключевое свойство инструмента - единая модель: элементы объявляются один раз, а
представления строятся из них. При рисовании по отдельности переименование
контейнера означает правку во всех диаграммах, и они неизбежно расходятся.

Модель была параллельно собрана в Structurizr DSL и LikeC4 на уровнях 1 и 2,
после чего варианты сравнивались на живом проекте.

## Решение

Модель C4 ведётся в LikeC4. Исходник - `docs/diagrams/model.c4`, картинки
пересобираются из него.

## Рассмотренные альтернативы

| Вариант                | Почему отклонён                                                                                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Structurizr DSL        | Эталон C4 и более зрелые диаграммы развёртывания, но синтаксис многословнее, а бесплатный плагин для JetBrains даёт только подсветку. Оставлен как запасной вариант, если упрёмся в развёртывание |
| PlantUML с C4-PlantUML | Нет единой модели: каждая диаграмма отдельна, элементы дублируются                                                                                                                                |
| Mermaid                | Рисуется на GitHub без установки, но поддержка C4 экспериментальна и единой модели тоже нет                                                                                                       |

## Последствия

Диаграммы развёртывания в LikeC4 моложе, чем в Structurizr. Если на этапе HLD
выяснится, что их выразительности не хватает, решение пересматривается.
