# Backend

Здесь появится код агентов и API. Наполняется по ходу курса.

## Что уже есть

[`prototype-multiagent/`](prototype-multiagent/) - прототип онлайн-пути на
LangGraph. Не MVP, а измерительный инструмент: проверяет схему из
[ADR-0007](../docs/adr/0007-multiagent-online-path.md) и даёт числа по профилю A
(CPU) до начала разработки. Хранилища заменены структурами в памяти, данные
синтетические.

## Планируемая структура

Повторяет блоки требований БФТ, чтобы отчёт о трудозатратах можно было сопоставить
с объёмом работ (условие C-06 договора):

| Каталог | Блок БФТ | Содержание |
|---|---|---|
| `app/ingestion/` | Блок 1 | Офлайн-конвейер загрузки: разбор документов, извлечение сущностей, построение графа, присвоение грифа |
| `app/agent/`, `app/retrieval/` | Блок 2 | Конечный автомат обработки запроса, обход графа, векторный поиск, переранжирование |
| `app/security/` | Блок 3 | Разграничение доступа, входные и выходные guardrails |
| `app/observability/` | Блок 4 | Трассировка, метрики |

## Принятые ограничения

- Разграничение доступа применяется как предикат в запросе к хранилищу, а не
  постобработкой ответа модели ([ADR-0002](../docs/adr/0002-access-control-before-retrieval.md)).
  Соответствие ролей и грифов определяется в одном месте; собирать запросы в обход
  этого слоя нельзя.
- Обработка запроса реализуется как конечный автомат, а не линейная цепочка
  промптов (FR-2.3).
- Тяжёлая мультимодальная обработка выносится в офлайн-конвейер: на профиле A
  она не укладывается в требования к латентности онлайн-запроса.
