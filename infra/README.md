## Решения, зафиксированные в этих файлах

- **Закрытый контур держится на маршрутизации, а не на дисциплине.** Служебная
  подсеть без NAT (`terraform/main.tf`), сеть `internal` в Compose помечена
  `internal: true`. Требование NFR-3, записанное как "не обращаемся к внешним
  API", нарушается первой же библиотекой, которая пойдёт за обновлением.
- **Профили железа.** Основная конфигурация - профиль A из NFR-1, инференс на
  CPU с квантованной моделью. Профиль B (арендованный GPU, одна A100 40 ГБ по
  ADR-0019) подключается отдельным override-файлом на время нагрузочного
  тестирования.
- **Секреты не хранятся в образах и файлах.** Terraform создаёт секрет и права
  на него, значения кладутся отдельно: состояние Terraform содержит значения
  ресурсов в открытом виде.
- **Состояние Terraform - в объектном хранилище с блокировкой.** Локальное
  состояние расходится при первом же применении со второй машины.
- **Веса моделей в репозиторий не попадают** (см. `.gitignore`) и в образ тоже:
  монтируются томом и версионируются записью реестра выпуска.
- **Тег образа - хеш коммита, не `latest`.** Иначе перезапуск контейнера меняет
  версию без следа в истории.
- **Метка `release`** передаётся из записи реестра через переменную окружения и
  попадает на все метрики: без неё канарейку нельзя отличить от базы.
