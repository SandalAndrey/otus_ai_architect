# Инфраструктура

Здесь появится `docker-compose` (либо Helm chart) для поднятия всего стека:
графовая и векторная базы, сервис инференса, приложение и контур наблюдаемости.

Наполняется по ходу курса, начиная с этапа HLD.

## Что предстоит учесть

- **Закрытый контур.** Обращения к внешним LLM-API исключаются архитектурно, а не
  организационно (NFR-2).
- **Профили железа.** Основная конфигурация описывает профиль A из NFR-1 - инференс
  на CPU с квантованной моделью. Профиль B (арендованный GPU) подключается отдельным
  override-файлом на время нагрузочного тестирования.
- **Сегментация сети.** В публичном контуре находится только приложение; хранилища и
  сервис инференса доступны исключительно изнутри.
- **Секреты.** Не хранятся в образах и конфигурационных файлах, выдаются из
  централизованного хранилища с ротацией.
- **Веса моделей** в репозиторий не попадают (см. `.gitignore`).
